Loop Statement Compiler

A beginner-friendly Python compiler front end for for, while, and do-while statements, with lexical analysis, parsing, AST construction, semantic checks, tests, and a Tkinter GUI.

View source on GitHub Read the README View screenshots

Compiler pipeline

Regex lexer → recursive-descent parser → dataclass AST → scoped semantic analyzer.

Desktop GUI

Tkinter editor with sample programs, token output, AST tree, semantic diagnostics, and compile status.

Tested language

Valid loops, nested loops, arithmetic expressions, syntax errors, undeclared variables, and duplicate declarations.

Quick start

git clone https://github.com/Phiraien/LoopStatementCompiler.git
cd LoopStatementCompiler
python -m unittest discover -s tests -p "test_python_compiler.py" -v
python gui.py

The compiler and GUI run locally; GitHub Pages hosts this static project showcase.
