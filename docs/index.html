Loop Statement Compiler

A beginner-friendly Python compiler front end for for, while, and do-while statements.

View the source on GitHub

What it demonstrates

Lexical analysis, recursive-descent parsing, dataclass AST construction, semantic checks, diagnostics, testing, and a Tkinter GUI.

Quick start

git clone https://github.com/Phiraien/LoopStatementCompiler.git
cd LoopStatementCompiler
python -m unittest discover -s tests -p "test_python_compiler.py" -v
python gui.py

├── Declaration: i
└── ForLoop
