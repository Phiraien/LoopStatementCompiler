Compiler Design mini project

Loop Statement Compiler

A beginner-friendly C, Flex, and Bison compiler front end for validating for, while, and do-while loops with AST generation and semantic analysis.

View source on GitHub Run the desktop GUI

Compiler front end

Flex lexer, Bison grammar, AST construction, scoped symbol checks, and honest syntax/semantic diagnostics.

Dark IDE GUI

Tkinter editor with samples, line numbers, compilation output, test results, and an expandable AST explorer.

Viva-ready

Documented subset, grammar notes, architecture, interfaces, test programs, and setup instructions for Windows/MSYS2 and Linux.

Quick start

git clone https://github.com/Phiraien/LoopStatementCompiler.git
cd LoopStatementCompiler
make
python -m gui.app

The hosted page is a project showcase and documentation site. The Tkinter desktop application and the C compiler run locally; they are not executed inside GitHub Pages.
